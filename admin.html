Gestor de productos

Añade, edita y borra productos sin tocar código. Los cambios se guardan como borrador en este navegador; descarga el JSON para publicarlos.

¿Cómo publico mis cambios en la web?
  1. Crea, edita o borra productos con el formulario y la tabla de abajo. Se guardan automáticamente como borrador en este navegador (no se pierden si recargas la página).
  2. Cuando termines, pulsa "⬇ Descargar products.json". Se descargará el archivo actualizado con todos tus productos.
  3. Sustituye el archivo data/products.json de la carpeta del proyecto por el que acabas de descargar.
  4. Sube ese cambio a donde tengas alojada la web (commit + deploy, subida por FTP, arrastrar el archivo en tu hosting, etc.). En cuanto el archivo esté actualizado, la web principal mostrará los productos nuevos automáticamente.
