Gestor de productos

Añade, edita y borra productos sin tocar código. Los cambios se guardan como borrador en este navegador; descarga el JSON para publicarlos.

¿Cómo publico mis cambios en la web?
  1. Crea, edita o borra productos con el formulario y la tabla de abajo. Se guardan automáticamente como borrador en este navegador (no se pierden si recargas la página).
  2. Cuando termines, pulsa "⬇ Descargar products.json". Se descargará el archivo actualizado con todos tus productos.
  3. Sustituye el archivo data/products.json de la carpeta del proyecto por el que acabas de descargar.
  4. Sube ese cambio a donde tengas alojada la web (commit + deploy, subida por FTP, arrastrar el archivo en tu hosting, etc.). En cuanto el archivo esté actualizado, la web principal mostrará los productos nuevos automáticamente.

☁️ Guardar cambios directamente en GitHub (opcional)

Conecta este panel con tu repositorio para que "☁️ Guardar en GitHub" actualice data/products.json directamente en tu repositorio, sin descargar ni subir nada a mano. La web se actualiza sola en 1-2 minutos. El token se guarda solo en este navegador y solo se usa para hablar con la API de GitHub, nunca se envía a ningún otro sitio.

Debe ser la misma rama que tengas seleccionada en GitHub Pages.
Créalo en GitHub → tu foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → "Generate new token". Dale acceso solo a este repositorio (Repository access → Only select repositories) y permiso Contents: Read and write. No compartas este token con nadie ni lo pegues en otro sitio.

✨ Autorrelleno desde Amazon

No podemos leer Amazon automáticamente solo con el link (el navegador lo bloquea y además Amazon prohíbe el scraping automatizado en su programa de afiliados). Pero puedes hacerlo así: abre el producto en Amazon → selecciona el texto de la página, idealmente desde el título hasta el final de "Acerca de este artículo" → cópialo (Ctrl+C, o mantener pulsado y "Copiar" en el móvil) → pégalo aquí abajo. Detectaremos nombre, precio, valoración, nº de valoraciones y ventajas automáticamente.

Las especificaciones ("Información técnica" / "Detalles del producto") suelen copiarse en un formato distinto al resto de la página. Selecciona y copia solo esa tabla en Amazon y pégala aquí para detectarla mejor.

Es una detección "best effort": revisa siempre los campos rellenados antes de guardar. La imagen y el link de afiliado nunca se autorrellenan, esos los pones tú a mano.
